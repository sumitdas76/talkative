# Asset inventory (no-capture project)

No live product UI was captured — Talkative is a native Windows desktop
app (Tkinter + system tray), not a website, so there is nothing to crawl
or screenshot. The two assets below were supplied by the user.

## `app-icon.png`

The real Talkative app icon: a white microphone glyph on a steel-blue
(#2563EB-ish) rounded-square ("squircle") badge, transparent background.
Use as the video's logo / brand mark, including the closing sting.
Source: `assets/icon_preview.png` in the Talkative source repo.

## `thumbnail-reference.png`

The user's own YouTube-thumbnail design for Talkative — a design
reference only, not a frame to composite directly. Establishes the
brand's real visual identity: navy (#0A1128-ish) heavy sans-serif
headline type, medium royal/steel blue (#2563EB-ish) accents and icon
badges, white background with light-blue accent panels, green checkmark
accents (#16A34A-ish) for reassurance/trust points, bold clean sans-serif
body type (reads like Inter/similar), rounded feature-icon badges in a
card-based grid layout. The four feature icons shown (Voice to Text,
Cleaned Up Mode, Auto Text & Dictionary, Dictation History) match this
video's headline features and can inform each feature beat's iconography
style (simple line/glyph icon inside a soft circular badge).
